# AI Types and How Language Models Work

AI를 분류할 때는 시스템이 무엇을 할 수 있는지와 어떤 방식으로 답을 만드는지를 구분한다. 제품을 설계할 때는 추상적인 능력 등급보다 실제 입력, 출력, 제약을 먼저 정한다.

## 1. 능력 범위와 작동 방식

| 분류 기준 | 유형 | 적용 |
| --- | --- | --- |
| 능력 범위 | 좁은 AI, 범용 AI, 초지능 AI | 범용 AI와 초지능은 개념적 분류다. 제품의 실제 정확도와 지원 작업은 별도로 검증한다. |
| 작동 방식 | 규칙 기반, 학습 기반 | 규칙 기반은 명시한 조건을 실행하고, 학습 기반은 데이터에서 얻은 패턴을 적용한다. |
| 학습 모델의 출력 | 판별, 생성 | 판별 모델은 분류나 점수 산출에, 생성 모델은 텍스트·이미지 같은 결과의 생성에 활용한다. |

하나의 서비스에서 모델이 문의를 분류하고, 규칙이 필수 승인 조건을 검사하며, 생성 모델이 답변 초안을 만드는 식으로 결합할 수 있다. 권한과 상태 변경 규칙은 서버에서 적용한다.

## 2. LLM이 답변을 만드는 과정

1. 토크나이저가 텍스트를 토큰으로 바꾼다.
2. 모델은 토큰과 위치 정보를 벡터로 표현하고, 트랜스포머의 어텐션으로 맥락을 반영한다.
3. GPT 계열의 자동회귀 모델은 다음 토큰의 확률 분포에서 토큰을 선택하고 이 과정을 반복한다.
4. API나 애플리케이션은 모델 출력에서 업무에 필요한 값을 읽고 검증한다.

초기 언어 모델은 통계적 패턴을 이용했고, 이후 순환 신경망을 거쳐 2017년 트랜스포머가 발표됐다. GPT 계열은 트랜스포머를 바탕으로 대규모 사전 학습과 프롬프트 기반 작업 수행을 발전시켰다. 모델이 매끄러운 답을 생성해도 답의 사실성은 업무 데이터나 검색 근거로 검증한다. [Attention Is All You Need](https://arxiv.org/abs/1706.03762) · [Language Models Are Few-Shot Learners](https://arxiv.org/abs/2005.14165)

## 3. 모델과 공급자 선택

후보를 비교할 때는 한국어 품질, 최대 입력·출력, 구조화 출력과 도구 호출 지원, 지연, 토큰 비용, 데이터 처리 조건을 같은 요청 세트로 평가한다.
